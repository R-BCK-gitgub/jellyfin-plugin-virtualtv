Temporary technical validation required by the v1 specification. It proves that the plugin can target an existing Jellyfin session and start a Jellyfin media item at an exact offset using the stock player.

Protected test: starts at the requested offset but continuously restores the item's pre-test Watched/Resume state after Jellyfin playback reports.

Native Live TV architecture test

This proof exposes the selected Jellyfin movie or episode through a real Jellyfin Live TV channel. The channel, not the source media item, must be the now-playing item so the source item's Watched/Resume state is not touched.
This test reuses the Target Jellyfin session, Start offset and Test media selected above. The source keeps its original timeline so rewind and bitmap subtitles can be validated against the same timestamps.
