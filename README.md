# Virtual TV for Jellyfin

Virtual TV plugin for Jellyfin 12.1.

## Full release

Current full release: **v2.0.0.0**

Developer: **R-BCK-gitgub**

Repository: **R-BCK-gitgub/jellyfin-plugin-virtualtv**

## Jellyfin plugin repository metadata

Virtual TV includes a Jellyfin-compatible `manifest.json` at the repository root.

Repository name:

`R-BCK-gitgub / Virtual TV`

Repository URL:

`https://raw.githubusercontent.com/R-BCK-gitgub/jellyfin-plugin-virtualtv/main/manifest.json`

Jellyfin uses this repository catalog to populate the Developer and Repository fields on the plugin details page.
The manifest URL must be reachable by the Jellyfin server; a private GitHub repository is not anonymously readable.
